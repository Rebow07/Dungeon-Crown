# 👑 Dungeon & Crown: Web Chronicles

O RPG Idle Medieval definitivo desenvolvido com **Next.js 16 (Turbopack)**, **TypeScript**, **Tailwind CSS** e **Impeccable Design System**.

---

## 🎮 Funcionalidades do Jogo

- **🎲 Combate Tático Dado D20 em Masmorras:** Batalhas por turnos interativas com rolagem de D20 (Caveira, Espadas, Coroa e Nat 20 Supremo).
- **⚔️ Caça & Clicker Idle RPG:** Arena de toque rápido com popups de dano flutuante e auto-idle contínuo.
- **🔁 Seletor de Repetições:** Opções de caça repetida (1x, 5x, 10x, 25x, 50x, ♾️ Auto).
- **📸 Perfil com Envio de Foto de Avatar:** Upload de imagens do dispositivo e 8 retratos medievais ilustrados.
- **⚡ Sistema de Custo Progressivo de Atributos:** Equilíbrio estratégico de atributos (Força, Agilidade, Vitalidade, Inteligência) sem builds apelativas (OP).
- **🐾 Pets Companheiros:** Fada da Luz, Lobo de Gelo, Dragão Bebê e Golem de Pedra com habilidades passivas e ativas.
- **🏹 Guilda de Mercenários (Auto-DPS):** Contrate Arqueiros, Cavaleiros e Magos para gerar dano por segundo contínuo.
- **🔨 Bigorna Rúnica (Forja):** Crafting de armas e armaduras de conjuntos lendários com materiais de masmorras.
- **🏪 Mercado da Cidade (NPC Shop):** Compra e venda de consumíveis, poções e relíquias.
- **⚙️ Aba de Configurações:** Edição de perfil, troca de avatares e redefinição (reset) de pontos de atributos.

---

## 🚀 Como Executar Localmente

```bash
# Instalar dependências
npm install

# Rodar o servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```

Abra o navegador em `http://localhost:3000`.
